Wie erkennt ImmoRadar ein mögliches Schnäppchen?

Der Vergleich berücksichtigt Kaufpreis, angenommene Kaufnebenkosten, geschätzte Renovierungskosten und einen von dir angegebenen Vergleichswert. Eine positive Differenz ist kein Nachweis eines unter Marktwert liegenden Angebots.

Formel: geschätzter Marktwert − (Kaufpreis + Kaufnebenkosten + Sanierungskosten). Der %-Abschlag bezieht sich auf den angegebenen Marktwert. Zusätzliche Risiken, Finanzierung, Energieeffizienz, Steuern und unvorhergesehene Mängel sind nicht enthalten.

Persönliche Daten werden lokal in diesem Browser gespeichert. Optional können freigegebene Datenfeeds per GitHub Actions aktualisiert werden; ein durchgehender Benachrichtigungsdienst benötigt ein separates Backend.
